User Guide

Use the Contractors and Vendors tabs in the header to browse every listing. Type a name, trade, or keyword into the search bar, or pick a work type from the dropdown, to narrow the results. Click any listing to see its full details and contact information.

To add, edit, or remove listings, click the Admin Login button in the top right corner and sign in with username admin and password changeme. From the dashboard you can manage all listings. Note that this is a demo, so any changes reset when the server restarts.

The Company Behind The Software

Hello, My name is Lucas Fredricks, I am a current computer science student at San Diego State University and the founder of Solomon Logistical Solutions. We are a software company focused on providing personalized software to small and medium construction companies. As the son of two parents that work in the construction industry I am quite familiar with the industry and its faults, especially when it comes to how archaic their information management systems are. Our current product is a web app that is used for storing, tracking and displaying vendors and subcontractors so that field and office workers alike have easy access to the information they need most frequently.

The Problem at Hand

My mother, an administrative assistant at a construction company, once described how they have a single spreadsheet called, “The Rolodex” that manages thousands of contacts for vendors and subcontractors sitting on a single desktop in the office. This means that anytime anyone needs to access contact information, someone has to go to that computer, search through a massive spreadsheet and if they manage to find what they were looking for, copy it down to their own device.

The Solution

The website you are on right now is our answer to modernizing this system. With this web application, we remove the aforementioned problem of having to physically make your way to the computer and dig through thousands of disorganized contacts simply to find a phone number. Using our software, it's as simple as going to the website and searching for whoever you want to get in contact with.

This Products Future

As mentioned, this software aims to solve a problem I came across in my real life. Over the course of the past few months, I have been in contact with the owners of the construction company my mother works for. After explaining the product and showing them the demo you are about to see, they expressed interest in purchasing the software and I have been working with them since.

A Brief Overview of the Source Code

This website was originally written in Python using Flask as a way for me to familiarize myself with Python web development. Regarding the use of AI in the development of this product, AI was used in brainstorming, debugging and to generate dummy data to display for the demo. Database development was done using SQLite through Flask-SQLAlchemy.

Guide to Self Hosting

Follow these steps to run the full version of this project, with its SQLite database, on your own computer. You will need Python 3.10 or newer and Git installed.

  1. Clone the main branch of the repository and move into it: 
    git clone --branch main https://github.com/Lfredricks/SLS.git
cd SLS
  2. Create a virtual environment and activate it: 
    python -m venv venv
venv\Scripts\activate        (Windows)
source venv/bin/activate     (macOS / Linux)
  3. Install the dependencies: 
    pip install -r requirements.txt
  4. Move into the app folder and create the database. This builds the SQLite file at sol_main/instance/solomon.db and fills it with sample listings and the admin account: 
    cd sol_main
python seed.py
  5. Start the website: 
    python app.py
    Then open http://localhost:5000 in your browser. Log in to the admin area at http://localhost:5000/admin/login with username admin and password changeme. Press Ctrl+C in the terminal to stop the server.

Unlike this demo, changes you make there are saved in the database file. To start over with fresh sample data, delete sol_main/instance/solomon.db and run python seed.py again.
